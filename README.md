# Setly

![Setly — 掛け持ちも、要望も守る。ライブの出演順づくり](apps/frontend/public/og.png)

**掛け持ちも、要望も守る。ライブの出演順づくり。**

Setly は、ライブの「出演順」をつくるためのアプリです。
曲順ではなく、バンドの出演順。30〜40 組が出るようなライブで、運営がいちばん頭を抱えるところを手伝います。

## 試してみる

[Setly](https://setly.jphack-2026.workers.dev)の「イベントを作成」で「サンプルから選ぶ」を選ぶと、名簿の登録と部のバンド数の設定まで済んだ状態ですぐに出演順づくりを試せます。イベント名は空欄でも作成でき、作成日時の名前になります。手元のCSVも同じ欄から取り込めます。

| サンプル名簿                                                                                   | バンド数 | 特徴                                         |
| ---------------------------------------------------------------------------------------------- | -------- | -------------------------------------------- |
| [定期ライブ（邦ロック）](https://setly.jphack-2026.workers.dev/samples/roster-regular-16.csv)  | 16       | 標準的な掛け持ち                             |
| [卒業ライブ](https://setly.jphack-2026.workers.dev/samples/roster-graduation-18.csv)           | 18       | 掛け持ちが多い（1人で最大7バンド）           |
| [アニソン・ボカロ](https://setly.jphack-2026.workers.dev/samples/roster-anime-vocaloid-14.csv) | 14       | 中心メンバー2人が5バンドずつ                 |
| [洋楽コピー](https://setly.jphack-2026.workers.dev/samples/roster-western-12.csv)              | 12       | 掛け持ちがほぼない                           |

曲は実在の曲、メンバー名はすべて架空です。ファイルは[apps/frontend/public/samples](apps/frontend/public/samples)にあります。

## 製品概要

### 背景（製品開発のきっかけ、課題等）

軽音サークルのライブみたいに、出演者が何組も掛け持ちしているイベントの出演順づくりは、思っている以上に大変です。

- 同じ人が連続で出ると、楽器の持ち替えや着替えが間に合わない
- 「この人は後半しか来られない」「このバンドはトリにしたい」みたいな要望が、あちこちから届く
- しかも最後は「盛り上がる流れにしたい」という、数字にできない気持ちもある

これを全部、スプレッドシートと頭の中でパズルしているのが今の運営です。1か所動かすと別のどこかが崩れて、確認だけで何時間も溶けます。

### 製品説明（具体的な製品の説明）

Setly は、**絶対に守りたいこと**と**なんとなくこうしたいこと**を分けて扱います。

1. 出演者フォームで、バンドとメンバー（掛け持ちも含めて）を集める
2. 「田中さんの出番は2組以上空ける」のような条件を、画面から選ぶか AI チャットに話しかけて追加する
3. 「自動生成」を押すと、ソルバーが必須の条件をすべて守った出演順をつくる
4. 「最後が盛り上がるようにして」と頼むと、AI がバンド紹介を読んで並べ替え案を出す
5. 気になるところは、ドラッグで動かして仕上げる

どの段階でも、条件ごとに「達成／違反」がその場で見えるので、どこが崩れたかすぐ分かります。

### 特長

#### 1. 必須の条件は、ソルバーが絶対に守る

掛け持ちの間隔、出演位置の指定、前後関係など、守らないといけない条件は数理最適化（OR-Tools CP-SAT）で解きます。両立しない条件があるときは、勝手にゆるめずに「解なし」と伝えます。

#### 2. 「盛り上がる順に」は、AI が気持ちをくみ取る

数字にできない希望は、AI（Gemini）がバンド紹介をもとに並べ替え案をつくります。ただし AI が必須の条件を破った案を出しても、違反の判定はプログラムがやって、ソルバーが「必須の条件を守ったまま一番近い並び」に直します。AI の自由さと、ルールの確実さのいいとこどりです。

#### 3. 並べ替えの「流れ」が見える

自動生成でも AI の提案でも、行がスルッと新しい位置にスライドします。どのバンドがどこへ動いたのか、目で追えます。掛け持ちの多いライブなら、掛け持ちしている全員に間隔の条件をまとめてかけることもできます。

### 解決出来ること

- 掛け持ちの出番がかぶる・近すぎる、という事故をなくせる
- 要望を全部覚えておかなくても、条件として残しておける
- 「これで本当に全部守れてる？」の確認作業がいらなくなる
- 何時間もかかっていた出演順づくりが、たたき台なら一瞬でできる

### 今後の展望

- バンドの演奏動画や音源から雰囲気を読み取って、紹介文を書かなくても「盛り上がる順」をつくれるようにしたい
- AI チャットから、そのまま自動生成まで実行できるようにしたい
- ログインと、運営チームでの共同編集

### 注力したこと（こだわり等）

- **ソルバーと AI の役割をはっきり分けたこと。** 守るべきルールは計算で、雰囲気は AI で。AI に違反の判定はさせていません。
- **条件の形を1つにそろえたこと。** 画面から追加した条件も、AI チャットが提案した条件も、ソルバーが受け取る条件も、全部同じ JSON Schema から型を生成しています。
- **AI の提案は、勝手に反映しないこと。** 変わる並びと、条件の達成・違反の増減を確認してから保存します。

## 開発技術

### 活用した技術

#### API・データ

- **Gemini API（Google AI Studio）**：自然言語で入力された要望を解釈し、出演順の条件の追加・変更を提案。
- **Cloudflare D1**：イベント、バンド、出演者、所属関係、制約、出演順、チャット履歴を保存。
- **Cloudflare Workers / Vercel**：Webアプリ・業務APIと、Pythonによる出演順の計算APIをそれぞれ実行。

#### フレームワーク・ライブラリ・モジュール

- **React / TypeScript / Vite**：フロントエンドの開発。
- **Tailwind CSS / dnd-kit**：画面のスタイリングと、ドラッグ＆ドロップによる出演順の編集。
- **Hono / Hono RPC**：業務APIの実装と、フロントエンド・バックエンド間の型共有。
- **FastAPI / Pydantic**：Pythonの計算APIと入力データの検証。
- **Google OR-Tools CP-SAT**：出演間隔、前後関係、位置固定などの条件を考慮した出演順の探索。
- **Drizzle ORM / Zod / JSON Schema**：DB操作、入力検証、TypeScriptとPythonで共有する制約形式の定義。
- **Vitest / Testing Library / Playwright / pytest**：単体テスト、API・DBの結合テスト、ブラウザ操作のテスト。

#### デバイス

- PC・スマートフォンのWebブラウザ。専用デバイスは不要。

### 独自技術

#### ハッカソンで開発した独自機能・技術

- **出演順のソルバー**：掛け持ちの間隔・位置・前後関係・出演できる範囲などを CP-SAT の制約にして解きます。→ [apps/solver/src/solver_constraints.py](apps/solver/src/solver_constraints.py)
- **AI の並べ替え案 × ソルバーでの修正**：AI の案に必須条件の違反があれば、ソルバーで一番近い守れる並びに直します。→ [apps/backend/src/services/chat/generate.ts](apps/backend/src/services/chat/generate.ts)、[apps/backend/src/services/chat/reorder.ts](apps/backend/src/services/chat/reorder.ts)（commit `d181427`）
- **条件の共通スキーマ**：フロント・バックエンド・ソルバーで同じ制約の定義を使います。→ [apps/schema](apps/schema)
- **並べ替えアニメーション**：並びが変わる前後の位置から行をスライドさせます。→ [apps/frontend/src/features/event/hooks/useScheduleFlip.ts](apps/frontend/src/features/event/hooks/useScheduleFlip.ts)

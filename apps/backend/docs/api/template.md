# ＜API名＞ API定義書

## 概要

目的・処理内容・対象の通信区間を短く書く。提案か実装済みかも明記する。

## API仕様

| 項目                   | 内容                             |
| ---------------------- | -------------------------------- |
| エンドポイント         | `＜パス＞`                       |
| HTTPメソッド           | ＜GET / POSTなど＞               |
| 呼出し元 → 呼出し先    | ＜対象の通信区間＞               |
| リクエスト・レスポンス | ＜application/jsonなど＞         |
| 認証                   | ＜要否・方式。未決定ならその旨＞ |

## リクエスト

送信する具体例をコードブロックで示し、必要な条件だけ補足する。GETなどボディがない場合は「ボディなし」と書き、必要ならクエリ付きURLを示す。細かなフィールド表は必要な場合だけ追加する。

## レスポンス

HTTPステータスと、正常・代表的なエラーの具体例をコードブロックで示す。JSON例には省略記号やコメントを入れない。

## 懸念点・未決定事項

未確定の仕様・確認事項を簡潔に書く。なければ「なし」。

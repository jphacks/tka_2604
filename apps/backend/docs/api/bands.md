# バンド削除API

## 概要

管理画面からバンド本体を削除する実装済みAPI。公開フォームのメンバー所属解除とは別の操作で、確認ダイアログで確定した場合だけ呼ぶ。

## API仕様

| 項目                   | 内容                                                              |
| ---------------------- | ----------------------------------------------------------------- |
| エンドポイント         | `/api/events/{eventId}/bands/{bandId}`                            |
| HTTPメソッド           | DELETE                                                            |
| 呼出し元 → 呼出し先    | ブラウザ → backend                                                |
| リクエスト・レスポンス | application/json                                                  |
| 所有者                 | [Cookieセッション](auth.md)のユーザー。未削除の所有イベントに限定 |

バンド本体・希望原文・対象バンドの所属・配置を削除し、他バンドの`order`は変更せず、空いた位置を未設定のまま残す。メンバー名簿、他バンドの所属、部、生成元が異なる制約、会話は保持する。最後のバンドも削除できる。

制約から参照されていても削除する。生成元sourceBandIdが削除対象を指す制約は、有効状態や対象IDにかかわらず同じD1 batchで削除する。生成元が異なる制約（生成元なしを含む）のJSONは変更しない。削除後に存在しない対象を参照する制約や範囲外の指定が残ることを許容する。

## リクエスト

有効なセッションCookieと同一オリジンの`Origin`が必要。認証・送信元の検証に失敗した場合は保存や外部通信を行わない。

```http
DELETE /api/events/event-1/bands/band-1
Content-Type: application/json
```

```json
{ "expectedUpdatedAt": "2026-10-18T00:00:00.000Z" }
```

`expectedUpdatedAt`は確認対象の名簿を取得したときの`updatedAt`。必須のISO日時で、未知のフィールドは受け付けない。確認後に別の保存が入った場合は409で何も削除しない。最新の日時を裏で取り直して競合を回避しない。

## レスポンス

成功はHTTP 200。

```json
{
  "eventId": "event-1",
  "bandId": "band-1",
  "updatedAt": "2026-10-18T00:01:00.000Z"
}
```

返却した更新日時は前回より進む。削除・所属・対象の配置・更新日時は同じD1 batchで確定し、途中で失敗した場合は全て取り消す。同じ更新日時での同時削除は片方だけ成功する。

| HTTP | code                | 条件                                     |
| ---- | ------------------- | ---------------------------------------- |
| 400  | invalid_input       | 不正なJSON                               |
| 401  | unauthorized        | 未認証・無効または期限切れのセッション   |
| 403  | invalid_origin      | 送信元不正・Origin欠落                   |
| 404  | event_not_found     | 存在しない・別所有者・削除済みイベント   |
| 404  | band_not_found      | このイベントに対象バンドがない           |
| 409  | event_save_conflict | 確認元のデータが古い                     |
| 422  | invalid_input       | 更新日時なし・不正日時・未知のフィールド |
| 500  | internal_error      | DB等の内部失敗。部分削除しない           |
